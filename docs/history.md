# Investigation history

Research and private development ran 3–9 November 2026 (Australia/Melbourne).
The project started from two identical official L5 copies. Community descriptions
were leads to reproduce, not a list of already proven independent causes.

- **G1/G2:** establish the L5C admission predicate, resident red-light effect and
  native Start-edge correction. Exclude unrelated L5C preference changes.
- **G3:** rejected research. An over-broad approach was not promoted.
- **G4:** isolate pending-Redline drain and third-lock races. This private phase
  removed Secret Mania; it is historical and not the final feature choice.
- **G5:** restore/retain Secret Mania at the owner's request and fix both
  demonstrated backup defects using its actual native task IDs.
- **G6:** add the atomic diverter PWM stop after coil/fault investigation;
  complete the large fault/multiplayer campaign, B6 investigation and bounded
  final feature/settings release gate. An image/burn package was prepared privately.
- **KH5:** public patch project. Fit `KH` into the existing two character slots,
  use numeric suffix five, and replace the ported numeric guard with original
  patch source. Recheck the changed guard, native checksum/display and nearby
  gameplay. KH5 is a different hash and is not silently substituted into G6 logs.

Earlier tools and evidence were retained rather than rewritten after a failed
fixture or changed hypothesis. A factory-message acknowledgement and independent
NVRAM initialization are prerequisites when moving between revision identities.
In the KH5 test setup, a reused G6 seed initially remained at a native startup
prompt; those starts were not counted as gameplay passes. Runtime-name collisions
also refused to overwrite old test state. Corrected attempts use separate paths.

The repository is a fresh, allowlisted publication tree. The private workspace,
its ROMs and earlier evidence were never initialized wholesale as this Git repo.
